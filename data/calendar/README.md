# Calendar lookup demo records

`demo-event-indices.json` contains three generated simulator fixture IDs and position DTOs. User selected normal-session seeding; supplied month/day location inputs must match once the producer is implemented. IDs are numeric simulator fixtures, not native calendar data or proof of native `CalendarEventID` representation.

This dataset supports only identity-to-position lookup. It is not a calendar event catalog, clock/date source, selected-event state, invitation model or native index-basis proof. Other Calendar gaps remain separate. [Contract](../../docs/specs/calendar-event-index-info.md).

At dataset authoring, runtime producer and behavioral verification are pending.
