# C namespace startup follow-up

Original-consumer failures exposed by [nil-member publication](../../specs/c-namespace-nil-members.md) are resolved individually. Existing modeled state belongs in `src/c_api`; unavailable backing systems receive named temporary workarounds, never a replacement arbitrary-member factory. Stock startup proof is collected once after all owned batches and attributed against frozen F0 rows.

## M1 conditions

The [condition contract](../../specs/c-factory-m1-conditions.md) deliberately supplies temporary false values for missing realm game-rules policy, ranged-slot display capability and the authoritative day/night clock. False preserves the removed factory's false-y consumer branches; it is not native evidence. Ranged-slot publication excludes Wrath; Hardcore is limited to the four profiles with failing original popup consumers; daytime is Forever-only. Raw guards preserve explicit providers.

F0 original-consumer RED applies because the producer source is unchanged between its source anchor and the test-only follow-up revision. New generated-documentation tests still require their own observed RED before final GREEN acceptance. Runtime proof remains pending.

## M2 state adapters

The [M2 contract](../../specs/c-factory-m2-adapters.md) reuses equipped-item catalog identity, known/book/pet spell membership, action-button registration and the supplied cooldown-viewer availability snapshot. Availability is compiled as shared state but remains published only for its documented modern profiles and Forever. The temporary Forever queries name separate missing keyring capability policy, lifetime talent-point award history and active spell/item targeting metadata; none is inferred from nearby inventory, level or talent data.

## M5 service and catalog inputs

The [M5 contract](../../specs/c-factory-m5-services.md) joins battle-pet species to existing pet-journal icons and exposes Forever's supplied transmog validity flags. Catalog storage is shared at compile time, but registration keeps other profiles' APIs unchanged and publishes only the requested validity member on Forever. Swap/skip predicates name missing battle action-legality systems rather than guessing from pet health.

Owned-house requests move from dashboard-only preload to an early named request definition, reused by preload. The absent ownership service produces a deferred empty event response; no synchronous timer fallback remains. Forever's empty purchased-tab list and false player-bag capability name missing bank metadata/capability models rather than treating legacy bank bag counts as tab records.
