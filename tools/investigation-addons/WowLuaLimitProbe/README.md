# WowLuaLimitProbe

Retail-client probe for Lua compiler local/register limits.

Install path used locally:

```text
/syncthing/World of Warcraft/_retail_/Interface/AddOns/WowLuaLimitProbe
```

Commands in-game:

```text
/llimit
/llimit 600
/llimit dump
/llimit clear
```

Results are stored in `WowLuaLimitProbeDB.last` and appended to
`WowLuaLimitProbeDB.history`.
